# Телефон пользователя доступен через команду `phone`

На этом ПК установлен PC Remote: телефон пользователя (Android) привязан к нему, и его
файлы доступны из терминала командой `phone` (она в PATH). Пути на телефоне — POSIX,
корень памяти телефона называется `/sdcard`. Пользуйся ей так же свободно, как ls/cat/cp.

```
phone roots                              важные папки: камера, скриншоты, загрузки, WhatsApp, Telegram
phone ls /sdcard/DCIM/Camera             содержимое папки (размер, дата, имя)
phone tree /sdcard/Download -d 3         дерево
phone find /sdcard "*.pdf"               поиск по маске имени
phone stat /sdcard/Download/x.pdf
phone cat /sdcard/Documents/notes.txt    текстовый файл в stdout
phone get /sdcard/DCIM/Camera/IMG_1.jpg ./IMG_1.jpg      скачать файл на ПК
phone put ./report.pdf /sdcard/Download/                 отправить файл на телефон
phone pull /sdcard/DCIM/Camera            зеркало папки в %LOCALAPPDATA%\pc-remote\phone\sdcard\DCIM\Camera
phone push ./out /sdcard/Download/out     отправить папку
phone rm | mkdir | mv                     удалить, создать, переименовать (rm удаляет без корзины — спроси пользователя)
```

Правила:
- Чтобы читать, искать или анализировать файлы телефона своими инструментами (Read, Grep, Glob),
  сначала сделай `phone pull <папка>` — файлы появятся локально в зеркале, работай с ними там.
  Повторный `pull` докачивает только новое.
- Большие папки (вся камера) тяни по частям или `find` сначала, чтобы не качать гигабайты.
- Перед `phone rm` на телефоне спроси подтверждение у пользователя.
- Если команда отвечает «телефон не подключён или доступ к файлам не включён» — попроси
  пользователя открыть «Мой ПК» на телефоне → Настройки → «Файлы телефона доступны для ПК».

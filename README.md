# pc-remote — удалённый доступ к ПК с телефона

Два приложения, никаких регистраций и сторонних сервисов:

- **PC Remote** для Windows (`pcapp/`) — окно с состоянием, при первом запуске само
  создаёт секрет и сертификаты, открывает порт в брандмауэре, прописывает
  автозапуск. Кнопка «Привязать телефон» показывает код на 5 минут.
- **Мой ПК** для Android (`android/`) — при первом запуске вводите адрес ПК и код,
  приложение получает секрет, запоминает сертификат ПК и больше ничего не
  спрашивает. Дальше: экран ПК, мышь, клавиатура, перезагрузка, выключение.

```
Телефон (Мой ПК) ──https, свой сертификат──► роутер (порт 8443) ──► ПК (PC Remote)
```

Нужен **белый IP** дома и один проброшенный порт на роутере. Трафик шифруется
собственным сертификатом ПК, телефон доверяет только ему.

Что умеет: экран ПК (масштаб щипком), касания = мышь, долгое нажатие = правая
кнопка, два пальца = прокрутка, режим тачпада, экранная клавиатура и горячие
клавиши, команды «перезагрузить / выключить / сон / заблокировать», кнопка
«Включить ПК» для выключенного компьютера (через ваш Wake-on-LAN канал ntfy, по
желанию). Ограничения: картинка JPEG без звука; экран блокировки и окна UAC не
видны (ограничение Windows), нужен автовход.

## Состав

| Папка      | Что это |
|------------|---------|
| `pcapp/`   | приложение для ПК: `main.py`, сборка в exe `build_exe.ps1` |
| `android/` | приложение для телефона: исходники Java, сборка `build.py` без Gradle |
| `relay/`   | ретранслятор (часть PC Remote), сертификаты `certs.py` |
| `agent/`   | захват экрана и ввод (часть PC Remote) |
| `web/`     | страница, которую показывает приложение на телефоне |
| `direct/`, `local/`, `launcher/` | запуск без приложений: скрипты для ПК и страница для браузера (см. ниже) |

## Сборка

Делается один раз на ПК.

### PC Remote.exe

Нужен Python 3 (https://www.python.org/downloads/, галочка *Add to PATH*).

```powershell
cd pc-remote\pcapp
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Результат: `pcapp\dist\PC Remote.exe`, один файл, можно положить куда угодно.
Данные (секрет, сертификаты, журнал) хранятся в `%LOCALAPPDATA%\pc-remote`.
Без сборки можно запускать и так: `python pcapp\main.py` (нужны пакеты из
`agent\requirements.txt`, `relay\requirements.txt` и `cryptography`).

### Мой ПК (APK)

Нужны JDK и Android SDK с `build-tools` и одной платформой (`platforms/android-33`).
Если SDK уже есть в `D:\Claude\android_sdk`, он найдётся сам.

```powershell
cd pc-remote\android
python build.py            # или: python build.py --sdk C:\путь\к\sdk
```

Результат: `android\out\pcremote.apk`. Ключ подписи `out\pcremote.keystore`
создаётся при первой сборке, **сохраните его**: обновления должны быть подписаны
тем же ключом.

## Установка

1. **ПК:** запустить `PC Remote.exe`. При первом запуске Windows спросит разрешение
   на правило брандмауэра — согласиться. В окне появится адрес вида
   `93.100.1.2:8443`.
2. **Роутер:** пробросить TCP-порт **8443** на ПК. На Wive-NG: *Сервисы →
   Переадресация портов*. У ПК должен быть постоянный адрес в домашней сети.
3. **Телефон:** установить `pcremote.apk`, открыть. На ПК нажать «Привязать
   телефон», ввести на телефоне адрес и показанный код → «Привязать». Готово.

Привязка делается один раз. Если на ПК пересоздать сертификаты или секрет
(удалить папку `%LOCALAPPDATA%\pc-remote`), телефон попросит привязаться заново.

## Как пользоваться

- Касание — клик, долгое нажатие — правая кнопка, двойной тап — двойной клик,
  ведёте пальцем — перетаскивание, два пальца вверх/вниз — прокрутка, щипок — масштаб.
- Кнопка ⌨ — клавиатура телефона плюс ряд клавиш (Esc, Tab, Alt+Tab, Win, Ctrl+C/V…).
- Кнопка ☰ — перезагрузка, выключение, сон, блокировка, режим тачпада, полный экран.
- Если ПК не в сети, показывается кнопка «Включить ПК» (когда в настройках ПК
  указан `ntfy_wake_url` — файл `%LOCALAPPDATA%\pc-remote\config.json`).

## Настройки ПК (`%LOCALAPPDATA%\pc-remote\config.json`)

| Ключ            | По умолчанию | Описание |
|-----------------|--------------|----------|
| `port`          | 8443         | порт, который слушает ПК и который проброшен на роутере |
| `public_ip`     | определяется | ваш белый IP; впишите вручную, если определился неверно |
| `ntfy_wake_url` | пусто        | канал ntfy для «Включить ПК», например `https://ntfy.sh/pcwake-…` |
| `max_width`     | 1280         | ширина картинки; меньше — быстрее |
| `quality`       | 55           | качество JPEG 1–95 |
| `fps`           | 12           | кадров в секунду, не больше |
| `monitor`       | 1            | номер монитора (0 — все сразу) |

После правки перезапустить PC Remote.

## Безопасность

- Соединение шифруется сертификатом, который ПК создал сам; телефон после
  привязки доверяет только этому сертификату (пиннинг по отпечатку SHA-256).
- Один секрет на 40 случайных символов, сравнение постоянного времени, после
  10 неверных попыток адрес блокируется на 10 минут. Код привязки действует
  5 минут и срабатывает один раз.
- Секреты и ключи не попадают в git и в журналы.

## Без приложений: запуск скриптами

Те же ретранслятор, агент и страница можно запускать без PC Remote и APK,
через браузер телефона:

- **`direct/`** — белый IP, свой сертификат, который один раз ставится в
  настройки телефона: `direct\install.ps1`, затем на телефоне открыть
  `https://ВАШ-IP:8443/ca.crt`, установить как сертификат ЦС, открыть
  `https://ВАШ-IP:8443`.
- **`local/`** — серый IP, без VPS: туннель Cloudflare на ПК, адрес меняется,
  страница-пускач `launcher/index.html` находит его через ntfy.
- **`relay/install.sh`** — свой VPS с доменом: ретранслятор на сервере за Caddy.

Подробности — в комментариях к скриптам.

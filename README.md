# pc-remote — удалённый доступ к ПК с телефона без VPN

Работает при сером IP: и ПК, и телефон сами подключаются к вашему серверу
(VPS), входящих подключений в домашнюю сеть не нужно. Трафик идёт по HTTPS,
как обычный сайт.

```
Телефон (браузер) ──wss──► VPS: relay.py + Caddy ◄──wss── ПК: agent.py
```

Что умеет:

- экран ПК на телефоне, касания = мышь (тап, долгое нажание = правая кнопка,
  перетаскивание, скролл двумя пальцами), экранная клавиатура и горячие клавиши;
- кнопки: перезагрузить, выключить, спящий режим, заблокировать;
- «Включить ПК», если ПК выключен (через существующий канал ntfy и домашний агент
  Wake-on-LAN);
- страницу можно добавить на рабочий стол телефона, выглядит как приложение.

Ограничения: картинка JPEG, без звука; экран блокировки и окна UAC не
показываются (ограничение Windows), для них нужен автовход.

## Три способа запуска

| | Напрямую (direct) | С VPS | Без VPS (local) |
|---|---|---|---|
| Когда подходит | у дома **белый IP** | есть свой сервер | ничего нет |
| Где ретранслятор | на ПК | на сервере | на ПК |
| Как ПК виден снаружи | проброс портов на роутере | сервер | туннель Cloudflare |
| Адрес страницы | постоянный | постоянный | меняется, нужен пускач |
| Задержка | минимальная | небольшая | выше |

Если у вас белый IP, берите **direct**: это самый быстрый и простой вариант.

## Напрямую (direct mode)

```
Телефон ──https──► роутер (порты 80/443) ──► ПК: Caddy → relay + agent
```

### 1. Домен

Браузеру нужен HTTPS, а сертификат на голый IP не выдают, поэтому нужно имя.
Бесплатно: https://www.duckdns.org (вход через GitHub или Google), создать имя
вида `myhome.duckdns.org`. Если ваш белый IP меняется, скопируйте со страницы
DuckDNS **token**, ПК будет сам обновлять адрес.

### 2. Роутер

Пробросить TCP-порты **80** и **443** на ПК. На Wive-NG это *Сервисы → Переадресация
портов* (Port forwarding). У ПК должен быть постоянный адрес в домашней сети,
например `192.168.1.250`: либо статический в Windows, либо привязка по MAC
в роутере (DHCP → static lease).

### 3. ПК

Нужен Python 3 (при установке галочка *Add to PATH*).

1. Скопировать папку `pc-remote` на ПК, например в `D:\Claude\pc-remote`.
2. PowerShell **от администратора** в `pc-remote\direct`:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1
   ```
   Первый запуск создаст `config.json` и напечатает секрет. Впишите в него
   `domain`, при необходимости `duckdns_token` и свой канал Wake-on-LAN
   в `ntfy_wake_url`.
3. `.\install.ps1` ещё раз: скачает Caddy, откроет порты в брандмауэре,
   зарегистрирует задачу «pc-remote direct» с автозапуском при входе.

Журналы: `direct\run.log`, `direct\caddy.log`. Сертификат Caddy получает сам
за несколько секунд, для этого порт 80 должен быть проброшен.

### 4. Телефон

Открыть `https://myhome.duckdns.org`, ввести секрет, добавить на главный экран.

## Состав

| Папка    | Где работает | Что это                                   |
|----------|--------------|-------------------------------------------|
| `relay/` | VPS (Linux)  | ретранслятор, aiohttp, за Caddy (HTTPS)    |
| `agent/` | ПК (Windows) | захват экрана, ввод, команды; задача в планировщике |
| `web/`   | VPS          | страница для телефона, раздаёт relay      |

## Установка

### 1. Домен

Браузеру для HTTPS нужен домен, а не голый IP. Бесплатно: https://www.duckdns.org —
создать имя вида `myhome.duckdns.org` и указать IP вашего VPS.

### 2. VPS (Ubuntu/Debian)

```bash
git clone <этот репозиторий>
cd RPG-Game/pc-remote
sudo bash relay/install.sh myhome.duckdns.org
```

Скрипт поставит relay как службу `pc-remote-relay`, Caddy с автоматическим
сертификатом и **напечатает секрет** (он же в `/opt/pc-remote/relay/config.json`).
Чтобы работала кнопка «Включить ПК», впишите в `config.json` адрес своего ntfy-канала
в `ntfy_wake_url` и перезапустите: `sudo systemctl restart pc-remote-relay`.

Проверка: `https://myhome.duckdns.org` открывается, просит секрет.

Порты 80 и 443 на VPS должны быть открыты (Caddy). Amnezia на том же сервере не
мешает: она работает на других портах.

### 3. ПК (Windows)

Нужен Python 3 (https://www.python.org/downloads/, при установке поставить галочку
*Add to PATH*).

1. Скопировать папку `agent/` на ПК, например в `D:\Claude\pc-remote\agent`.
2. Скопировать `config.example.json` → `config.json`, вписать `relay_url`
   (`https://myhome.duckdns.org`) и `secret` с сервера.
3. PowerShell от администратора в этой папке:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1
   ```
Агент запускается сразу и при каждом входе в Windows, при сбое перезапускается.
Журнал: `agent.log` рядом с `agent.py`.

### 4. Телефон

Открыть `https://myhome.duckdns.org`, ввести секрет. В меню браузера —
«Добавить на главный экран».

## Без VPS (local mode)

Ретранслятор и агент работают на ПК, наружу их выставляет `cloudflared`
(бесплатный «quick tunnel» Cloudflare, без аккаунта). Адрес туннеля меняется
при каждом запуске, поэтому ПК публикует его в свой ntfy-канал, а на телефоне
стоит маленькая страница-пускач `launcher/index.html`, которая этот адрес
читает и открывает экран ПК одной кнопкой.

```
Телефон: launcher ──читает адрес──► ntfy.sh ◄──публикует адрес── ПК
Телефон ──wss──► *.trycloudflare.com ──туннель──► ПК: relay + agent
```

### ПК

Нужен Python 3 (при установке галочка *Add to PATH*).

1. Скопировать всю папку `pc-remote` на ПК, например в `D:\Claude\pc-remote`.
2. PowerShell **от администратора** в `pc-remote\local`:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\install.ps1
   ```
   Первый запуск создаст `config.json` и напечатает **секрет** и **канал адреса**.
   Если хотите кнопку «Включить ПК», впишите в `config.json` свой канал
   Wake-on-LAN в `ntfy_wake_url`.
3. Запустить `.\install.ps1` ещё раз. Он скачает `cloudflared.exe`, поставит
   зависимости и зарегистрирует задачу «pc-remote local» с автозапуском при входе.

Журнал: `local\run.log`. В нём видно адрес туннеля.

### Телефон

Открыть `launcher/index.html`. Проще всего положить его куда-нибудь с постоянным
адресом, например включить GitHub Pages для этого репозитория, тогда страница
будет по адресу вида `https://<логин>.github.io/RPG-Game/pc-remote/launcher/`.
Можно и просто открыть файл с телефона, но тогда его надо переслать себе.

Один раз ввести канал адреса, канал включения и секрет. Дальше страница сама
показывает, в сети ли ПК, и кнопкой «Открыть экран ПК» переходит на текущий адрес.
Добавьте её на главный экран.

Ограничение: пока ПК выключен, туннеля нет, поэтому на пускаче доступна только
кнопка «Включить ПК» (через ваш домашний агент Wake-on-LAN).

## Как пользоваться

- Касание — клик, долгое нажатие — правая кнопка, двойной тап — двойной клик,
  ведёте пальцем — перетаскивание, два пальца вверх/вниз — прокрутка.
- Кнопка ⌨ — клавиатура телефона плюс ряд клавиш (Esc, Tab, Alt+Tab, Win, Ctrl+C/V…).
- Кнопка ☰ — перезагрузка, выключение, сон, блокировка, режим тачпада, полный экран.
- Если ПК не в сети, показывается кнопка «Включить ПК».

## Настройки агента (`agent/config.json`)

| Ключ        | Значение по умолчанию | Описание                                |
|-------------|-----------------------|-----------------------------------------|
| `max_width` | 1280                  | ширина картинки; меньше — быстрее       |
| `quality`   | 55                    | качество JPEG 1–95                      |
| `fps`       | 12                    | кадров в секунду, не больше             |
| `monitor`   | 1                     | номер монитора (0 — все сразу)          |

Кадры отправляются только пока страница открыта на телефоне и только когда
картинка меняется, так что в простое агент почти не нагружает ПК и сеть.

## Безопасность

- Один общий секрет (40 случайных символов) для ПК и телефона, сравнение
  постоянного времени, после 10 неверных попыток адрес блокируется на 10 минут.
- Секрет не попадает в git (`config.json` в `.gitignore`) и в журналы.
- Сменить секрет: поменять в обоих `config.json`, перезапустить relay и агент,
  на телефоне в меню «Сменить секрет».

# pc-remote — удалённый доступ к ПК с телефона

Два приложения, никаких регистраций и сторонних сервисов:

- **PC Remote** для Windows (`pcapp/`) — окно с состоянием, при первом запуске само
  создаёт секрет и сертификаты, открывает порт в брандмауэре, прописывает
  автозапуск. Кнопка «Привязать телефон» показывает код на 5 минут.
- **Мой ПК** для Android (`android/`) — при первом запуске вводите адрес ПК и код,
  приложение получает секрет, запоминает сертификат ПК и больше ничего не
  спрашивает. Дальше: экран ПК, мышь, клавиатура, перезагрузка, выключение.

```
Телефон (Мой ПК) ──https, свой сертификат──► роутер (порт 8443) ──► ПК (PC Remote)
```

Нужен **белый IP** дома и один проброшенный порт на роутере. Трафик шифруется
собственным сертификатом ПК, телефон доверяет только ему.

Что умеет: экран ПК (масштаб щипком), **звук с ПК**, касания = мышь, долгое
нажатие = правая кнопка, два пальца = прокрутка, режим тачпада, клавиатура с
залипающими Ctrl/Alt/Shift/Win, быстрые кнопки (Alt+Tab, диспетчер задач,
громкость, медиа…), команды «перезагрузить / выключить / сон / заблокировать»,
три профиля качества включая **эконом** (≈2 кадра/с, 640 px, без звука), пауза
видео при свёрнутом приложении, автопереподключение без перезагрузки страницы,
кнопка «Включить ПК» для выключенного компьютера (через ваш Wake-on-LAN канал
ntfy, по желанию).

Расширенное взаимодействие с ПК:

- **Claude Code и git с телефона** — кнопка `>_` в шапке: на ПК запускается
  настоящий терминал (Claude Code или PowerShell в выбранной папке проекта), на
  телефоне — терминальное окно с быстрыми кнопками (`/rc`, `/help`, `/clear`,
  Enter, Esc, Ctrl+C, стрелки, свои команды) и рядом git (status, pull, push,
  log, diff, commit, stash). Внизу строка ввода: пишете сообщение для Claude и
  отправляете. Экран ПК для этого не нужен. Папки проектов — `projects` в
  `config.json` ПК.
- **Файлы** в обе стороны: фото и документы с телефона попадают в
  `Загрузки\PC Remote` на ПК; папки ПК (Загрузки, Рабочий стол, Изображения,
  Документы — `share_dirs` в настройках) можно просматривать и скачивать на
  телефон.
- **Буфер обмена ПК → телефон**: скопировали что-то на ПК — на телефоне
  появляется «Буфер ПК», одно нажатие копирует его в телефон. В обратную
  сторону — «Вставить текст».
- **Макросы**: свои кнопки из шагов (`keys: Meta,r`, `text: notepad`,
  `key: Enter`, `wait: 500`, `url: …`, `shell: git pull`, `cmd: lock`),
  появляются в панели клавиатуры.
- **Несколько мониторов**: переключение в меню, включая «все сразу».
- **Качество по сети**: на мобильном интернете само переходит в эконом.
- **Журнал событий**: кто и когда подключался, привязки, команды, файлы.

В обратную сторону, с ПК на телефон:

- **«Найти телефон»** — кнопка в окне PC Remote: телефон громко звонит и
  вибрирует даже на беззвучном, экран включается, пока не нажать «Выключить».
- **Трансляция экрана телефона на ПК** — в меню приложения на телефоне: экран
  телефона (и его звук, Android 10+) идёт на ПК и открывается там во весь экран.
  Телефоном можно пользоваться как обычно: включили видео — оно на мониторе.
  Переключатель «Заглушить телефон на время трансляции» выключает звук на самом
  телефоне, на ПК он играет как обычно. Остановить можно из меню или из
  уведомления.

Для этого приложение на телефоне держит фоновую связь с ПК (уведомление «Связь с
ПК») и поднимается при включении телефона. На MIUI/HyperOS разрешите приложению
«Автозапуск» и «Без ограничений» по батарее, иначе система его усыпит. Ограничения: экран блокировки и окна UAC не видны
(ограничение Windows), нужен автовход.

## Состав

| Папка      | Что это |
|------------|---------|
| `pcapp/`   | приложение для ПК: `main.py`, сборка в exe `build_exe.ps1` |
| `android/` | приложение для телефона: исходники Java, сборка `build.py` без Gradle |
| `relay/`   | ретранслятор (часть PC Remote), сертификаты `certs.py` |
| `agent/`   | захват экрана и ввод (часть PC Remote) |
| `web/`     | страница, которую показывает приложение на телефоне |
| `direct/`, `local/`, `launcher/` | запуск без приложений: скрипты для ПК и страница для браузера (см. ниже) |

## Готовые сборки и автообновление

Собирать самому ничего не нужно. При каждом изменении в репозитории GitHub сам
собирает `PC-Remote.exe` и `pcremote.apk` и выкладывает их на странице
**Releases**: https://github.com/troublefack1-hue/-/releases/latest

Обе программы обновляются сами:

- **PC Remote** проверяет новую версию при запуске и раз в сутки, скачивает и
  перезапускается уже новой. Кнопка с номером версии в окне — обновить вручную.
  Отключить: `"auto_update": false` в `config.json`.
- **Мой ПК** (Android) проверяет раз в 6 часов, скачивает APK и показывает
  системное окно установки — одно нажатие «Установить» (Android не позволяет
  ставить обновления совсем без участия). При первом разе телефон попросит
  разрешить установку из этого приложения.

Чтобы автосборка подписывала APK всегда одним ключом (иначе обновление не
встанет поверх старой версии), ключ хранится в **секретах репозитория**, а не в
коде: *Settings → Secrets and variables → Actions → New repository secret*:
`ANDROID_KEYSTORE_B64` (файл ключа в base64) и `ANDROID_KEYSTORE_PASS` (пароль).
Без них сборка подпишет APK временным ключом: установится, но обновляться сам
не сможет.

## Сборка вручную

Если нужно собрать самому.

### PC Remote.exe

Нужен Python 3 (https://www.python.org/downloads/, галочка *Add to PATH*).

```powershell
cd pc-remote\pcapp
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Результат: `pcapp\dist\PC Remote.exe`, один файл, можно положить куда угодно.
Данные (секрет, сертификаты, журнал) хранятся в `%LOCALAPPDATA%\pc-remote`.
Без сборки можно запускать и так: `python pcapp\main.py` (нужны пакеты из
`agent\requirements.txt`, `relay\requirements.txt` и `cryptography`).

### Мой ПК (APK)

Нужны JDK и Android SDK с `build-tools` и одной платформой (`platforms/android-33`).
Если SDK уже есть в `D:\Claude\android_sdk`, он найдётся сам.

```powershell
cd pc-remote\android
python build.py            # или: python build.py --sdk C:\путь\к\sdk
```

Результат: `android\out\pcremote.apk`. Ключ подписи `out\pcremote.keystore`
создаётся при первой сборке, **сохраните его**: обновления должны быть подписаны
тем же ключом.

## Установка

1. **ПК:** запустить `PC Remote.exe`. При первом запуске Windows спросит разрешение
   на правило брандмауэра — согласиться. В окне появится адрес вида
   `93.100.1.2:8443`. Программа сама прописывается в автозапуск: после включения
   ПК и входа в Windows она стартует свёрнутой и ждёт телефон (в окне статус
   «ожидает телефон» / «телефонов на связи: N»). Нужен автовход в Windows, чтобы
   это происходило без клавиатуры.
2. **Роутер:** пробросить TCP-порт **8443** на ПК. На Wive-NG: *Сервисы →
   Переадресация портов*. У ПК должен быть постоянный адрес в домашней сети.
3. **Телефон:** установить `pcremote.apk`, открыть. На ПК нажать «Привязать
   телефон», ввести на телефоне адрес и показанный код → «Привязать». Готово.

Привязка делается один раз. Если на ПК пересоздать сертификаты или секрет
(удалить папку `%LOCALAPPDATA%\pc-remote`), телефон попросит привязаться заново.

## Как пользоваться

- Касание — клик, долгое нажатие — правая кнопка, двойной тап — двойной клик,
  ведёте пальцем — перетаскивание, два пальца вверх/вниз — прокрутка, щипок — масштаб.
- Кнопка ⌨ — клавиатура телефона плюс ряд клавиш (Esc, Tab, Alt+Tab, Win, Ctrl+C/V…).
- Кнопка ☰ — перезагрузка, выключение, сон, блокировка, режим тачпада, полный экран.
- Если ПК не в сети, показывается кнопка «Включить ПК» (когда в настройках ПК
  указан `ntfy_wake_url` — файл `%LOCALAPPDATA%\pc-remote\config.json`).

## Настройки ПК (`%LOCALAPPDATA%\pc-remote\config.json`)

| Ключ            | По умолчанию | Описание |
|-----------------|--------------|----------|
| `port`          | 8443         | порт, который слушает ПК и который проброшен на роутере |
| `public_ip`     | определяется | ваш белый IP; впишите вручную, если определился неверно |
| `ntfy_wake_url` | пусто        | канал ntfy для «Включить ПК», например `https://ntfy.sh/pcwake-…` |
| `max_width`     | 1280         | ширина картинки; меньше — быстрее |
| `quality`       | 55           | качество JPEG 1–95 |
| `fps`           | 12           | кадров в секунду, не больше |
| `monitor`       | 1            | номер монитора (0 — все сразу) |

После правки перезапустить PC Remote.

## Безопасность

- Соединение шифруется сертификатом, который ПК создал сам; телефон после
  привязки доверяет только этому сертификату (пиннинг по отпечатку SHA-256).
- Секрет никогда не попадает в URL: он идёт в заголовке `Authorization` или
  первым сообщением внутри WebSocket, поэтому не оседает в истории браузера и
  журналах.
- Один секрет на 40 случайных символов, сравнение постоянного времени, после
  10 неверных попыток адрес блокируется на 10 минут (таблица блокировок
  ограничена по памяти; за прокси учитывается реальный адрес клиента). Код
  привязки действует 5 минут и срабатывает один раз.
- Лимиты: не больше 4 телефонов одновременно, событие от телефона ≤ 64 КБ, кадр
  от агента ≤ 4 МБ; агент ограничивает число кликов, длину текста и комбинаций.
- Секреты и ключи не попадают в git и в журналы.

Известные слабые места (осознанные компромиссы):

1. **Привязка по принципу «доверие при первом подключении».** Если в момент
   ввода кода между телефоном и ПК стоит злоумышленник, он может перехватить
   секрет. Привязывайтесь из домашней сети или по мобильному интернету, не
   через чужой Wi-Fi. Код живёт 5 минут и один раз.
2. **Один секрет на всё.** Тот, кто его узнал, управляет ПК. Смена: удалить
   `%LOCALAPPDATA%\pc-remote\config.json`, перезапустить PC Remote, привязать
   телефон заново.
3. **Порт открыт в интернет.** Любой может попробовать подключиться; его
   остановят TLS, секрет и блокировка после 10 попыток, но сам факт наличия
   сервиса виден.
4. **Локальный туннель в приложении** слушает `127.0.0.1` без пароля: другое
   приложение на том же телефоне может до него достучаться, но без секрета
   ничего не сделает.
5. **Канал ntfy для включения** защищён только секретностью имени канала.

## Без приложений: запуск скриптами

Те же ретранслятор, агент и страница можно запускать без PC Remote и APK,
через браузер телефона:

- **`direct/`** — белый IP, свой сертификат, который один раз ставится в
  настройки телефона: `direct\install.ps1`, затем на телефоне открыть
  `https://ВАШ-IP:8443/ca.crt`, установить как сертификат ЦС, открыть
  `https://ВАШ-IP:8443`.
- **`local/`** — серый IP, без VPS: туннель Cloudflare на ПК, адрес меняется,
  страница-пускач `launcher/index.html` находит его через ntfy.
- **`relay/install.sh`** — свой VPS с доменом: ретранслятор на сервере за Caddy.

Подробности — в комментариях к скриптам.
